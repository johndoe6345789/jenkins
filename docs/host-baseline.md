## Reproduce on a fresh Debian host

1. Add third-party apt repos: for each row in the table above, drop the key
   at `key_path` (fetch from `key_url` where set; for `_bundled_` keys the
   first apt install of the package brings it in) and the file in
   `/etc/apt/sources.list.d/`.
2. `apt-get update && apt-get install` the package list in
   `docs/host-apt-manual.txt`. Trim the desktop subset (`xfce4-*`,
   `gnome-*`, `terminator`, `google-chrome-stable`, `nomachine`) for a
   headless rebuild.
3. `usermod -aG docker $USER` and re-login.
4. Install nvm (URL in the JSON), then `nvm install` each version listed.
5. `pip install` each tracked pip package.
6. `dpkg -i` the `.deb` installs (URLs in the JSON).
7. Clone this repo, then:
       python3 scripts/setup.py bootstrap

`setup.py install-host-deps` will eventually automate steps 1–6 from the
JSON. For now they're manual.
